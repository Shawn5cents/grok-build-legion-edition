# 0.2.112 — 2026-08-05

## Legion Features

- Connected provider models appear in the live model catalog without restarting
  the session.
- Legion mode includes an in-TUI role assignment menu for the orchestrator,
  explorer, architect, implementor, and verifier.
- DeepSeek-compatible streams repair fragmented parallel tool calls, empty
  arguments, missing call IDs, and incorrect finish reasons.
- Subagent roles can switch once to a configured fallback after exhausting HTTP
  429 retries.
- The bounded DAG verifies implementations with observed command evidence and
  permits at most one repair and one verifier recheck.

## Reliability and Distribution

- The verifier can execute tests, builds, linters, and endpoint probes without
  receiving file-editing tools.
- Legion updates resolve through this repository's `-legion` GitHub releases
  and keep the `legion`, `grok`, and `agent` entry points synchronized.
- Headless CI no longer mixes synthetic terminal diagnostics with the runner's
  physical microphone state.
