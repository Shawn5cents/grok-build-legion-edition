# Local Incident Record: Provider Calls Failed

This is a historical record from one macOS deployment on 2026-07-31. The
private configuration and logs used during diagnosis are not committed, so the
timeline is an operator report rather than independently reproducible project
evidence.

## Timeline

Times are local to the affected machine.

| Time | Reported event |
|---|---|
| ~09:00 | Earlier Kilo gateway model resolutions were removed from the local configuration. |
| 13:00-13:28 | The watcher reported that three provider keys were absent from the TUI process environment. Requests fell through to session-token authentication and received 401 responses. |
| 13:28-13:32 | After a TUI restart restored the environment, Anthropic requests lacked the required version header and OpenAI requests used an incompatible backend. Both produced 400 responses. |
| 13:29-13:31 | The local watcher exited under `set -u` after processing malformed state. |
| 13:32 | Local provider settings were changed to use the Anthropic Messages and OpenAI Responses request shapes. |
| 13:33-13:47 | The watcher repeatedly alerted on an earlier failure because its deduplication state was unstable. |
| 13:35 onward | The replacement TUI session was reported healthy during the remaining observation window. |

## Reported causes

1. The long-lived parent shell did not contain newly configured provider
   environment variables, so the TUI could not resolve the intended keys.
2. The local Anthropic and OpenAI model overrides used incompatible request
   shapes.
3. The local watcher trusted malformed state and removed deduplication entries
   too early.

## Resolution and limits

The local operator restarted the TUI, corrected the provider overrides, and
rewrote the watcher state handling. Six spawnable roles subsequently completed
tasks, and the configured orchestrator model returned HTTP 200 in a direct API
probe.

This does not prove that all roles, fallback transitions, or future sessions
will work. See [`verification.md`](verification.md) for the exact scope of the
reported checks.
