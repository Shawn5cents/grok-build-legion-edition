# Security Policy

Grok Build Legion Edition is an independent community fork and does not use or
represent xAI's vulnerability-reporting programs.

## Supported versions

Security fixes are provided for the latest published Legion release. Older
releases and development snapshots may be asked to upgrade before a report is
investigated.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow:

https://github.com/Shawn5cents/grok-build-legion-edition/security/advisories/new

Include the affected version, platform, reproduction steps, impact, and any
suggested mitigation. Remove API keys, tokens, personal data, and private
endpoint details from all evidence.

Please do not open a public issue or pull request for an undisclosed
vulnerability. Maintainers will acknowledge a private report on a best-effort
basis, coordinate a fix and release when confirmed, and credit the reporter if
requested.
