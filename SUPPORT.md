# Support

Legion is a community-maintained project. Support is best effort and is
provided through this repository.

## Getting help

- Use [GitHub Issues](https://github.com/Shawn5cents/grok-build-legion-edition/issues)
  for reproducible bugs and focused feature requests.
- Include `legion --version`, your operating system, installation method,
  selected provider type, and minimal reproduction steps.
- Redact credentials, tokens, account identifiers, private URLs, and local
  configuration before posting logs.

Provider outages, account billing, model availability, and vendor-specific
rate limits must be handled by the relevant provider. Questions about the
upstream Grok Build product should be directed to xAI.

Security vulnerabilities belong in the private process described by
[`SECURITY.md`](SECURITY.md), never in a public issue.
